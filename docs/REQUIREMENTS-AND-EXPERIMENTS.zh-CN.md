# 用户需求与实现状态

更新时间：2026-11-18（新加坡时间）。当前源码版本为 `1.0.6`，版本唯一来源是 `package.json`。本文记录最新产品范围和未完成验收；旧版 Hub 管理功能的历史试探集中在 [实现试探与接续注意事项](EXPERIMENTS-TIMELINE.zh-CN.md)。源码、隔离测试、安装文件和 T3 真实运行状态分别核验，不能相互替代。

自动绑定补充：Agent 入口只读查询 T3 已登记项目、会话及工作树，精确唯一匹配后锁定当前项目。技能先取状态、核对项目，再自动携带路径调用，不要求用户配置。未知或共享进程归属不符时拒绝；未绑定可重试，成功后不能用参数切换项目。源码隔离用例及真实本机登记查询分别验证；旧 MCP 进程仍等待自然重连，不能据此宣称所有未来子智能体均已实测。

本轮补充：记忆只读写当前项目，取消全局读写入口并保留旧数据；主会话与子智能体使用同一边界。无项目上下文时拒绝访问，不回退到最近项目。同仓子项目分别隔离，linked 工作树保留共享与私有范围，旧模糊工作树 ID 不猜归属。向量卡提供真实测试按钮，报告模型、维度、耗时与失败原因。独立 MLX 后台服务不依赖打开 oMLX，测试只发送固定无隐私短句，不改变记忆或模型配置。T3 不提供可信会话绑定的第三方 MCP 场景保持明确不可用，不能声明全部 Agent 已接通。

## 当前产品范围

Hub 精简为**遥测 + Memory**：

- 聊天标题旁计划 pill 显示当前主会话计划和步骤状态，格式为“第 N / M 步”，蓝环与步骤展开已在本机核验。
- 顶栏显示周额度、平台图标居中的双环额度（外圈周额度、内圈真实 5 小时额度）与 Git 历史入口。
- 输入区显示生成速度、缓存、Token、费用；上下文信息放在模型选择器旁。
- Hub 仅保留 Memory 工作区及记忆相关的宿主配置状态。

遥测交互口径：持续显示会话均速；可回退到同一聊天的末轮速度，不跨聊天借值。标题进度格式为“第 N/M 步”；真实截图已验证额度环与均速显示，环围绕平台图标，周额度在外、5 小时额度在内，Muse 的 300 分钟 Session 已修复并真实显示双环。Git 入口左移后右侧平台图标仍可见。

Memory 接入口径：Agent 记忆总开关、状态检查与安全接入、首次接入提示词共同构成首次使用流程。固定 CLI 入口为 `~/.t3/bin/t3-memory-setup`。开关关闭只阻止 Agent MCP 读写并保留库内容；Hub 的人工搜索、读取和维护仍可用。启用时自动检查后续新增的本机 T3 provider。已安装 router 按每次工具调用读取开关；本次代码更新前已运行的旧 MCP 进程需自然重连以加载新代码，无需为了开关状态专门新开会话。

Dream 自动整理关闭；Hub 不再提供 Dream 入口或自动启动定时器。Hub 自建编排/路由及通用宿主设置、Skills、MCP、插件和 Hooks 管理均已退役。旧配置和历史记录保留，删除管理界面不代表删除数据，也不代表这些配置仍会生效。普通记忆搜索、读取、写入和人工维护保留。

## 远程计划与 Git 历史的实施契约

当前 Connect 环境先读取同一 `threadId` 的原生计划投影，并可使用当前项目范围内的私有镜像补足；镜像仅存当前主计划，权限为仅用户可读写并由 Git 忽略。本机已验证镜像项目/步骤与当前计划匹配。无计划或读取失败时隐藏入口，不回退到其他会话或项目。

Git 图谱首屏采用提交概要优先，用户选择某条提交后再补取差异详情。MacBook Connect 的 `readFile` 已确认可用，但选中仓库没有提交记录，不能作为历史 UI/性能验证。缓存、远端详情 UI/API 和跨机完整流程仍未验收。

## 运行状态与安全边界

- Hub 连接状态只表明配置或连接记录可读；不能单独证明 T3 当前会话已经加载、更不能证明宿主实际执行。
- Magpie 管理的原生配置不由 Hub 覆写；若无法在权威来源安全补接，应显示待处理。AGY 空 MCP 配置会提示 `agy_native_helper_compatibility`，优先保留其原生后台文本助手能力。已有 MCP 的 AGY 配置才允许在保留现有条目的基础上检查接入。
- Muse / AGY 当前 Hook 不支持或未接入，只表示 Hook 自动提醒路径不可用，不表示 MCP 读写能力不可用。PowerContext 当前与 Hub 使用同一份 Memory 库。向量检索是查找机制，不会限制记录持续增长或自动设定库容量上限。
- 关闭 Agent 访问开关不会删除、压缩或清空已有 Memory；用户仍可通过 Hub 人工维护。每次 router 工具调用均检查开关；已运行的旧 MCP 进程仅在加载新代码时需要自然重连。
- 远程项目必须使用其 Connect 环境和会话身份；远端读取失败时不借用本机路径或上一会话的数据。
- 保留用户既有记忆、模型偏好、项目隔离、人工维护能力和未托管指令；不借由文档更新清理旧配置。
- 不运行真实 Dream，不为验收发起额外 AGY 模型请求，也不重启 T3。
- 后端/access/计划镜像/记忆连接模块已局部热更新；额度环与均速有本机截图验收。顶部记忆开关、首次提示词入口、计划蓝环与向量/MCP 信息均已热更新并核验。本文不表示跨机全流程完成。
